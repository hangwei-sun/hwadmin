# HwAdmin 通用移动端接入指南

`admin-ui/mobile/` 为 HwAdmin 提供通用移动端预留，不绑定学习、电商等具体业务，也不绑定线上服务器或微信账号。PC 后台继续使用原有 Element Plus；移动端使用 Wot UI V2。

## 技术基线与来源

- uni-app + Vue 3 + TypeScript + Pinia，面向微信小程序和 H5。
- 基于 unibest base `8277fab1eccf7464d4fe63310309ad5c35cc2ce9` 精简工程配置：保留文件路由、布局、动态清单、自动导入与 UnoCSS；移除上游演示、双 Token 假设和非目标平台依赖。上游许可见客户端 `LICENSE.unibest`。
- Wot UI V2 使用 npm 包 `@wot-ui/ui@2.4.0`，不混用旧包 `wot-design-uni`。
- 独立 package、锁文件和工作区，避免移动端所需的 Vite 5 工具链影响 PC 后台。

## 安装与本地运行

在仓库根目录执行（Node 22.22.2+ / 24.15+ / 26+，pnpm 10）：

```powershell
pnpm --dir admin-ui mobile:install
Copy-Item admin-ui/mobile/.env.example admin-ui/mobile/.env.local
pnpm --dir admin-ui mobile:dev
```

H5 地址为 `http://127.0.0.1:9000/`。H5 默认通过 Vite 代理把 `/api` 转发给 `http://127.0.0.1:8000`。需要接口实测时在 WSL 启动后端：

```bash
bash scripts/wsl-dev.sh serve
```

如本地后端地址不同，在 `.env.local` 配置 `VITE_DEV_PROXY_TARGET`。登录使用已有会员账号，后台管理员账号不能代替会员账号。

## 微信小程序预留

```powershell
pnpm --dir admin-ui mobile:dev:mp
pnpm --dir admin-ui mobile:build
```

微信开发者工具分别导入 `admin-ui/mobile/dist/dev/mp-weixin/` 或 `dist/build/mp-weixin/`。未配置 AppID 时生成游客模式配置，仅供查看界面，不代表可以提交微信审核。

具体业务项目在本地环境文件配置：

```dotenv
VITE_APP_TITLE=业务应用名称
VITE_WX_APPID=你的微信小程序AppID
VITE_API_ORIGIN=https://你的后端域名
```

`VITE_API_ORIGIN` 只填写后端 origin，不包含 `/api`，不带查询参数。真机需配置可达后端；正式环境必须 HTTPS，并在微信平台配置合法 request 域名。开发者工具配置默认开启域名检查。构建可以在未配置域名时生成通用产物；请求时会明确提示配置缺失，不伪造连通结果。

AppSecret、签名私钥、管理员凭证不得写入任何 `VITE_*` 变量。变量会进入客户端产物。生产变量可使用忽略的 `.env.production.local`；修改环境配置后重启或重新构建。

本项目未绑定小程序上传凭证，未执行上传、审核或线上发布。

## Wot 组件与主题

- `pages.config.ts` 以 easycom 映射 `^wd-(.*)` 到 `@wot-ui/ui/components/wd-$1/wd-$1.vue`，按需编译，不全量注册。
- `tsconfig.json` 引入 `@wot-ui/ui/global`，提供组件类型提示。
- `src/App.vue` 引入 V2 主题基础样式，`src/style/theme.scss` 统一品牌变量，覆盖 `page` 与 `.wd-root-portal`；`src/theme.ts` 将其映射到 ConfigProvider 的 V2 变量，避免懒加载默认主题及弹出层覆盖品牌色。
- `src/layouts/default.vue` 放置 ConfigProvider、Toast 和 Dialog。新增页面通过 `definePage` 标记 `layout: default` 即可使用统一布局；小程序中不可依赖 App.vue 的模板包裹页面。
- `src/pages-components/` 是独立示例分包，展示按钮、标签、输入框、开关、进度、Tabs、Popup 与 Toast。页面反馈调用 `useToast()`，异步操作处理 loading 与失败状态。

```vue
<script setup lang="ts">
import { useToast } from '@wot-ui/ui'
const toast = useToast()
definePage({ layout: 'default', style: { navigationBarTitleText: '业务页面' } })
</script>

<template>
  <view class="page">
    <wd-button @click="toast.success('操作成功')">提交</wd-button>
  </view>
</template>
```

`src/pages.json`、`src/manifest.json` 与自动声明文件由配置生成，不手改、不提交。业务分包在 `vite.config.ts` 的 `UniPages.subPackages` 注册。底部导航从 `pages.config.ts` 扩展。

## 接口与认证

`src/http/` 是唯一请求入口，基于 `uni.request`：

- `code: 1` 解包返回 `data`，`code: 0` 等拒绝 Promise；HTTP/业务码 401 都清理会员会话并引导登录；403 保持登录并交给页面提示。
- 支持 HTTP 错误、网络失败及非 JSON/非法协议响应，不显示服务端原始异常。
- 请求路径只能是站内相对路径，已登录请求注入 `Authorization: Bearer <token>`；公开登录和健康检查不附带 Token。
- 会员令牌独立保存在 `hwadmin.mobile.member-token`，不复用 PC 管理员会话；密码不持久化，不假设 JWT 或 refresh token。
- 列表类型 `PageResult<T>` 保持 `{ list, total }`，与 HwAdmin 后端契约一致。

已接入的会员基础与可选能力接口：

| 接口 | 用途 | 鉴权说明 |
| --- | --- | --- |
| `GET /api/index/ping` | 公开健康检查、框架版本与安装状态 | 公开免登录 |
| `POST /api/user/login` | 会员账号密码登录，保存 token / user | 公开免登录 |
| `POST /api/user/register` | 会员自主账号注册（可选能力） | 公开免登录 |
| `POST /api/user/resetPassword` | 账号找回与密码重置（可选能力） | 公开免登录 |
| `POST /api/user/wechatLogin` | 微信授权登录与凭证诊断（缺配置明确提示） | 公开免登录 |
| `POST /api/user/upload` | 会员头像与安全附件上传（可选能力） | 需会员登录 |
| `GET /api/user/info` | 读取服务端会员资料 | 需会员登录 |
| `POST /api/user/logout` | 服务端吊销当前会员令牌 | 需会员登录 |

### 外部信息集中收集与诊断

移动端涉及微信 AppID、服务端 API 地址等外部配置时，统一使用 `src/utils/external-config.ts` 的 `checkExternalConfig()` 函数集中诊断：
- 客户端仅注入可公开的 `VITE_APP_TITLE`、`VITE_WX_APPID`、`VITE_API_BASE_URL`；
- `AppSecret`、微信支付私钥与管理员密钥**严禁写入任何前端环境变量**，必须保留在服务端环境变量中；
- 当缺少微信配置时，调用 `wechatLogin` 会返回业务码 `10001` 与待办项标识 `CONFIGURE_WECHAT_CREDENTIALS`，提供明确的诊断说明，严禁伪造授权成功。

## 验证与交付

### 1.4.2 认证配置补充

普通 debug/local 环境不再回传密码恢复 Token。业务需实现 `UserPasswordResetRequested` 监听器，将凭证发送到已验证的会员渠道并在真实发送成功后返回 `true`；缺渠道时返回 `CONFIGURE_PASSWORD_RECOVERY_DELIVERY`。测试用凭证仅在 testing 环境输出，不能作为生产找回密码方案。

微信模拟映射仅在 testing 启用；身份映射不再匹配可编辑的 bio/用户名。已有旧映射时须先确认绑定真实微信 AppID 后迁移，不能通过重新注册或替换会员身份解决（历史变更见 [CHANGELOG](CHANGELOG.md)）。

```powershell
# 移动端：类型、请求契约测试、微信生产构建、H5 生产构建
pnpm --dir admin-ui mobile:check
# PC 后台回归
pnpm --dir admin-ui vue-tsc
pnpm --dir admin-ui build
```

移动端 `build` 默认生成微信小程序，`build:h5` 生成 `dist/build/h5/`；H5 默认 hash 路由，部署时将产物发布到独立站点，并反代同源 `/api`，或配置完整 HTTPS origin 并在后端允许目标 H5 来源。产物、依赖、环境文件均不提交。

参考：[Wot V2 安装](https://v2.wot-ui.cn/guide/quick-use.html)、[主题](https://v2.wot-ui.cn/guide/custom-theme.html)、[unibest](https://www.unibest.tech/)。
