# HwAdmin 单机生产运维与灾难恢复手册

> 更新日期：2026-10-28  
> 目标场景：单机高可用、物理机/虚拟机、容器化编排、纯内网政企内网交付

## 一、生产环境基准架构

HwAdmin 单机生产基线由以下模块构成：
- **Web 接入层**：Nginx 1.26+（负责反向代理、静态资源缓存与 `/uploads/` 脚本禁执行防护）
- **应用运行时**：PHP-FPM 8.2+（推荐 8.3/8.4），开启 Opcache 生产级缓存加速
- **高速缓存与防爆破锁**：Redis 7+（单机实例，带强口令认证）
- **持久化数据库**：MySQL 8.0+（主推）或 PostgreSQL 16+（原生双栈兼容）

## 二、Docker Compose 生产容器编排与双库切换 (D01)

### 1. 快速启动生产容器

```bash
# 1. 复制环境变量配置文件
cp .env.docker.example .env

# 2. 设置强口令（严禁使用默认示例口令）
# 修改 .env 中的 DB_PASS, DB_ROOT_PASSWORD, REDIS_PASSWORD

# 3. 校验编排语法
docker compose config

# 4. 启动默认环境 (Nginx + PHP-FPM + Redis + MySQL 8.0)
docker compose up -d
```

### 2. 双数据库无缝切换 (MySQL ↔ PostgreSQL)

HwAdmin 采用 Compose Profiles 机制隔离不同数据库引擎，避免同时启动占用资源：

- **切换至 PostgreSQL 16**：
  在 `.env` 中修改：
  ```ini
  COMPOSE_PROFILES=pgsql
  DB_DRIVER=pgsql
  DB_HOST=hwadmin-postgres
  DB_PORT=5432
  DB_USER=hwadmin_app
  PG_USER=hwadmin_app
  ```
  执行启动：
  ```bash
  docker compose --profile pgsql up -d
  ```

## 三、灾备备份与一键数据恢复 SOP (D05)

项目提供开箱即用的灾备工具脚本 `scripts/backup-restore.sh`：

### 1. 灾备健康基准体检

在执行日常运维或自动备份前，校验磁盘空间与目录读写：

```bash
bash scripts/backup-restore.sh check
```

**检查项包括**：
- 磁盘可用空间检测（< 500MB 自动告警）
- `server/runtime` 与 `server/public/uploads` 可写权限
- 识别当前运行中的数据库驱动

### 2. 创建灾备全量快照

全量备份包含：核心 `.env`、数据库 Dump（MySQL/PostgreSQL/SQLite）、公共附件 `public/uploads`、受控私有附件 `runtime/storage/private`：

```bash
bash scripts/backup-restore.sh backup [输出目录]
# 默认归档至 backup/hwadmin_backup_YYYYMMDD_HHMMSS.tar.gz
# 同步生成对应 .sha256 校验和文件
```

### 3. 一键灾难恢复

```bash
bash scripts/backup-restore.sh restore backup/hwadmin_backup_20261028_113513.tar.gz
```

**恢复流程自动化保障**：
1. 自动执行 SHA-256 完整性哈希校验，防止损坏包或篡改注入；
2. 现有 `.env` 自动留存安全备份（`.env.pre_restore_*`）；
3. 自动将数据库结构与数据回填至目标引擎；
4. 恢复物理附件并自动重置正确文件归属权限。

## 四、磁盘耗尽与异常演练处置策略

1. **磁盘耗尽（No Space Left on Device）**：
   - 框架日志默认滚动保留，日志路径位于 `server/runtime/log/`；
   - 临时清理：`rm -rf server/runtime/log/* server/runtime/cache/*`；
   - 紧急排查：`du -sh server/runtime/* server/public/uploads/*` 定位大文件。
2. **只读目录故障（Read-only File System）**：
   - 确保 Web 运行用户（`www-data` / `nginx`）拥有 `server/runtime/` 和 `server/public/uploads/` 755 读写权限；
   - 修复命令：`chown -R www-data:www-data server/runtime server/public/uploads`。
3. **配置错误回退（Config Rollback）**：
   - 当修改 `.env` 导致服务异常时，恢复至 `.env.pre_restore_*` 或执行 `bash scripts/wsl-dev.sh rollback`。

## 五、纯内网冷部署与出站审计 (D04)

针对政企内网高密网络环境，HwAdmin 提供 100% 离线部署包与冷机验收机制：

1. **生成无外链生产离线发布包**：
   ```bash
   python scripts/build-release.py
   # 产出：release/hwadmin-release-v0.1.0.zip 与 SHA-256
   ```
2. **执行断网网络命名空间出站连接审计**：
   ```bash
   bash scripts/offline-acceptance.sh release/hwadmin-release-v0.1.0.zip
   ```
   **验收标准**：
   - 在仅保留回环设备 `lo` 的无外网 Linux 命名空间内完整执行；
   - 经由 `strace` 全面截获 `connect`/`sendto`/`sendmsg` 系统调用；
   - 非本地回环（Loopback）外部出站网络连接必须严格为 **0 次**。
