数据库与管理员设置

配置主数据库连接参数及初始超级管理员登录凭据。

1. 数据库配置

MySQL 8.0+
PostgreSQL 16+
SQLite 3 (零配置极速体验)
⚡ 零配置极速模式：免安装 MySQL 或 PostgreSQL 数据库服务！数据库文件将自动创建于 server/runtime/hwadmin.sqlite，全自动建表与种子初始化，极速开箱即用。

2. 初始超级管理员账号

以字母开头，3-30 位字母/数字/下划线
至少 8 位，且必须包含字母和数字
